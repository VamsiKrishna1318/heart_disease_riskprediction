# ❤️ Heart Disease Risk Prediction

A Machine Learning-powered web application that predicts the likelihood of heart disease based on patient health parameters. The project combines a trained Logistic Regression model with an interactive user interface to provide real-time predictions.

## 🚀 Live Demo

🔗 https://heartdiseaseriskprediction-beta.vercel.app/

Try the application and predict heart disease risk in real time.

---

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. This project aims to assist in early risk assessment by leveraging Machine Learning techniques to analyze patient health data and predict the probability of heart disease.

The application allows users to enter medical parameters and instantly receive a prediction generated by a trained machine learning model.

---

## 🎯 Objectives

- Predict the risk of heart disease using patient health data.
- Build and train a Machine Learning model.
- Provide real-time predictions through an easy-to-use interface.
- Demonstrate the end-to-end Machine Learning workflow from data preprocessing to deployment.

## 📊 Dataset Features

The model uses various medical attributes, including:

- Age
- Gender
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG Results
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Number of Major Vessels
- Thalassemia
